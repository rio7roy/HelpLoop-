HelpLoop is a hyperlocal mutual-aid board. a shared space where neighbors post either a request for help (blood, food, a ride, tutoring, essentials, anything) or an offer to give it, and everyone nearby sees both boards update live. When someone responds, the post shows who's helping; once it's done, it's marked resolved and adds to a running "neighbors helped" count so the community can see its own impact. There's no login  you just pick a name the first time you post or help. It runs as a single web app with a real shared backend, so every post and update is visible to anyone with the link, not just the person who made it.
